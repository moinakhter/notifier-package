Only Alert on Actual Exceptions

When checked, the notifier service will only dispatch emails and channel alerts if an actual Python exception or traceback is captured. Standard log messages without an error traceback will be silently stored in history without buzzing your phone or inbox.

Log Retention Period (Days)

Notification logs and delivery history older than this threshold are automatically pruned daily to keep your database fast and lightweight. Default is 15 days. Set to 0 to keep logs indefinitely.

Client-Side Filtering in Python

You can also filter logs directly at the source using the notifier-service-hub Python client: 

# 1. In standard Python logging (only notify for actual exceptions):
from notifier_service.client import NotifierLoggingHandler

handler = NotifierLoggingHandler(
    endpoint='http://your-notifier-server:8000',
    project='{{ selected_project.slug }}',
    notify_exceptions_only=True,       # Only sends when record has exc_info / traceback
    allowed_severities=['ERROR', 'CRITICAL'], # Ignore WARNING and INFO
)

# 2. Or using NotifierClient directly:
from notifier_service.client import NotifierClient

client = NotifierClient(
    endpoint='http://your-notifier-server:8000',
    project='{{ selected_project.slug }}',
    notify_exceptions_only=True,
)
